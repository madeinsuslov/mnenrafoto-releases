## Оформление

| Светлая тема | Тёмная тема |
| --- | --- |
| ![Светлая тема](https://raw.githubusercontent.com/madeinsuslov/mnenrafoto-releases/v0.2.0-alpha.3/assets/alpha3-light.png) | ![Тёмная тема](https://raw.githubusercontent.com/madeinsuslov/mnenrafoto-releases/v0.2.0-alpha.3/assets/alpha3-dark.png) |

Кнопка с монитором, солнцем или луной находится в верхней панели рядом с языком.
Выбор сохраняется между запусками. Для существующих профилей по умолчанию остаётся
тёмная тема, для новых используется системная. Светлая тема нейтральная светло-серая.

Тема интерфейса не меняет цвета фотографий, белую бумагу, экспорт или печатное изображение.
Это проверяется сравнением пикселей preview/экспортного canvas и HTML печати.

## Белые промежутки: важные детали

- По умолчанию **0 мм**, прежняя раскладка сохраняется.
- Промежутки и внешние поля видны в preview и учитываются в печати.
- Положительные промежутки в этой Alpha доступны **только с полями**, без borderless.
- Перед применением программа показывает новые размеры областей и просит подтвердить их.
- Четыре фото ровно **100×150 мм не помещаются на A4 в сетке 2×2**: нужны 200×300 мм,
  а лист имеет 210×297 мм. Для точного размера используйте меньше фото или больший лист.
- Если поля меньше аппаратных полей драйвера, печать останавливается с объяснением;
  увеличьте поля или верните промежуток 0 мм. Начать проверку можно с полей 5 мм.

## Epson L8050: исправление требует проверки

Вместо безусловной пользовательской бумаги используется подходящий именованный формат
драйвера; перед печатью проверяется итоговый DEVMODE. Если формат не подтверждён,
программа не должна молча печатать на унаследованном A4.

**Физически на L8050 исправление ещё не подтверждено.** Автоматические проверки не
заменяют тест на конкретном драйвере. Метрические 100×150 мм и 4×6 дюйма
(101,6×152,4 мм) не подменяются друг другом. Если драйвер публикует только 4×6,
выберите этот формат явно; его успешная печать не подтверждает 100×150 мм.

Прежний подтверждённый маршрут L1210/L1250 и калибровка сохранены. Новая Alpha целиком
не заявляется как физически проверенная: перед тиражом нужен один пробный лист.

## Как обновиться

1. Закройте МНЕНРАФОТО.
2. Скачайте **Setup** для установки либо **Portable** для запуска без установки.
3. Setup и обычный Portable используют прежний профиль приложения. При необходимости
   заранее сделайте резервную копию заказов и пресетов. Не удаляйте данные программы.
4. Не запускайте одновременно старую и новую версии. Проверьте настройки и один лист
   перед массовой печатью.

Сборки `TEST L8050` использовали отдельный тестовый профиль: его настройки автоматически
не заменяют профиль обычной публичной версии.

## Проверки перед публикацией

TypeScript renderer/electron, production build, регрессии тем, промежутков, L8050,
Epson golden fixture, GDI lifecycle, размещения листа, форматов бумаги, локализации,
прогресса, заказов, фото и режима документов. В Playwright проверяются сохранение темы,
системные события Chromium, читаемость UI и неизменность изображения между темами.
Реальные задания на принтер во время подготовки релиза не запускались.

## Ограничения Alpha

- Это **предварительная версия**, возможны ошибки.
- EXE не подписаны цифровым сертификатом; Windows SmartScreen может предупредить.
  Проверяйте источник загрузки и SHA-256; не отключайте защиту Windows целиком.
- Новые форматы, реальная смена темы Windows и поведение конкретных драйверов требуют
  дополнительной проверки на компьютере пользователя.
- HEIC зависит от системных расширений HEIF/HEVC Windows.
- Профиль «Госуслуги» предварительный; проверяйте актуальные требования услуги.
- [Полный список ограничений](https://github.com/madeinsuslov/mnenrafoto-releases/blob/main/KNOWN_ISSUES.md).
